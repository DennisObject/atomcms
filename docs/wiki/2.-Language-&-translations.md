# Language and translations

## Set the default language

1. Set the language in `.env`. Use the name of a file in `lang/`:

   ```dotenv
   APP_LOCALE=da
   ```

2. Run `php artisan config:cache` in production, or `php artisan config:clear` while you develop.

A language that a user chose in their settings wins over the default.

## Add a language

1. Copy `lang/en.json` to a new file named after the locale.
2. Translate the values. Keep the English keys and the placeholders as they are.

   ```json
   {
       "Home": "Hjem",
       "Community": "Fællesskab",
       "Shop": "Butik"
   }
   ```

3. Add a row to `website_languages` with the `country_code` and the display `language`. The language then appears in the language menu.

Locale names such as `br` and `se` are part of Atom today. Do not rename them in an update.

## Contributing a language

- Add the language to `WebsiteLanguageSeeder`.
- Wrap new text in Blade with `{{ __('Your text') }}` and add its translation to the JSON files. See [Laravel localization](https://laravel.com/docs/13.x/localization#using-translation-strings-as-keys).
