# Shop and PayPal setup

Players buy website balance with PayPal. They spend the balance on shop items and packages. What an item does in the game depends on your emulator.

Test with the sandbox first. Then go live.

## Sandbox

1. Create a sandbox REST app in the [PayPal Developer Dashboard](https://developer.paypal.com/dashboard/applications/sandbox).
2. Add the details to `.env`:

   ```dotenv
   PAYPAL_MODE=sandbox
   PAYPAL_CURRENCY=USD
   PAYPAL_SANDBOX_CLIENT_ID=your-sandbox-client-id
   PAYPAL_SANDBOX_CLIENT_SECRET=your-sandbox-client-secret
   PAYPAL_WEBHOOK_ID=your-sandbox-webhook-id
   ```

3. In the same PayPal app, add a webhook for `https://hotel.example/api/paypal/webhook`. The address must be public and use HTTPS. Choose these events:
   - **CHECKOUT.ORDER.APPROVED**
   - **PAYMENT.CAPTURE.COMPLETED**
4. Put the webhook **ID** (not its address) in `PAYPAL_WEBHOOK_ID`. `PAYPAL_NOTIFY_URL` does not create the webhook and does not replace the ID.
5. Run `php artisan config:cache`.
6. Set up the [scheduler](1.-Installing-Atom-CMS.md#scheduler-and-queues). Every five minutes, Atom checks pending orders. This works even if the buyer never reaches the success page. To run it by hand, use `php artisan paypal:reconcile --limit=100`. In live mode, it can capture approved real orders.

Atom checks the webhook signature and the captured payment before it credits a user. See [PayPal webhooks](https://developer.paypal.com/api/rest/webhooks/).

### Test it

1. Pay with a sandbox buyer. The balance must go up once.
2. Repeat the success URL and the webhook. The balance must not go up again.
3. Cancel a checkout. Nothing must be credited.
4. Buy the items and packages your emulator supports. Check that they arrive.

## Live mode

1. Use the credentials of your live PayPal app:

   ```dotenv
   PAYPAL_MODE=live
   PAYPAL_LIVE_CLIENT_ID=your-live-client-id
   PAYPAL_LIVE_CLIENT_SECRET=your-live-client-secret
   PAYPAL_WEBHOOK_ID=your-live-webhook-id
   ```

2. Add the same two events and your live HTTPS address to the live app. Sandbox and live use different credentials and webhook IDs.
3. Rebuild the config cache.

Keep the client secrets in `.env` or your secret store. Atom has no setting to switch off certificate checks (`PAYPAL_VALIDATE_SSL`).

## Currency

Set `PAYPAL_CURRENCY` to a currency your PayPal account supports. Set the shop prices to match. Before you change the currency, check the pending orders. Their saved amount and currency must stay clear.

In [headless mode](10.-Headless-mode.md), the shop uses `/api/v1/shop`. After payment, PayPal returns the buyer to your frontend shop page, with `order` and `payment_status` in the address.

The first version of this PayPal guide came from Puffin. This version follows Atom's verified webhook and reconcile flow.
