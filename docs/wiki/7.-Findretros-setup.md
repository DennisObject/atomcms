# FindRetros setup

1. Add your FindRetros name to `.env`:

   ```dotenv
   FINDRETROS_NAME=your-findretros-name
   FINDRETROS_ENABLED=true
   ```

2. Refresh the config cache: `php artisan config:cache`.
3. Vote with a normal user account. You must return to the hotel after you vote.

If an HTTPS request fails with cURL error 60, fix the PHP certificate bundle. See [troubleshooting](1.-Installing-Atom-CMS.md#troubleshooting). Keep certificate checks on.
