# Atom CMS documentation

Atom CMS is the website for your retro hotel. It works with the Arcturus Morningstar and Ada emulators. It has two themes, Atom and Dusk. It can also run without a website, as an API for your own frontend ([headless mode](10.-Headless-mode.md)).

## Start here

1. [Install Atom CMS](1.-Installing-Atom-CMS.md).
2. Choose a [theme](3.-Theme-system.md) and a [language](2.-Language-%26-translations.md).
3. Connect your [client](8.-Nitro-setup.md).
4. Set up the [shop](9.-Shop-setup.md).

The [documentation index](README.md) lists every guide.
