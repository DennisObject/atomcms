# Maintenance mode

Atom has two kinds of maintenance mode.

## Atom maintenance page

Use this when the hotel is open to staff only.

1. In Housekeeping, under CMS settings, set `maintenance_enabled=1`.
2. Set `maintenance_message` to the text visitors see.
3. Set `min_maintenance_login_rank` to the lowest rank that may still sign in.

To reopen the hotel, set `maintenance_enabled=0`.

You can show progress on the page. Add rows to the `website_maintenance_tasks` table:

| Column | Meaning |
| --- | --- |
| `user_id` | The person doing the work |
| `task` | A description of the work |
| `completed` | Shows the done mark |

In [headless mode](10.-Headless-mode.md), your frontend shows the page. Read `maintenance` and `maintenance_message` from `GET /api/v1/status`.

## Laravel maintenance mode

`php artisan down` and `php artisan up` turn on Laravel's own maintenance mode. Use them for updates. See [updating an installed hotel](1.-Installing-Atom-CMS.md#updating-an-installed-hotel).

It runs before Atom's page. Staff cannot skip it, even with a high rank.
